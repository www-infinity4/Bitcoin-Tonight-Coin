# Bitcoin Tonight — Infinity Service Access

Bitcoin Tonight Coin is a service-access application. It is not presented as a speculative asset, exchange-traded currency, or automatically appreciating investment.

A viewer uses one Infinity service unit to create a structured entertainment request for a creator. The request can describe a Twitter/X Space, live discussion, performance, show, or community program. The creator chooses whether to accept, go live, schedule elsewhere, or decline. Acceptance credits the creator ledger; declining returns the locked unit.

## Recorded service fields

- creator and claim state
- session title and purpose
- audience or project potential
- topic tags
- product relationship
- optional Space reference
- request, acceptance, live, decline, and completion history
- ledger entries for every service-unit movement

## Current operating boundary

The GitHub Pages build operates entirely on the device and stores its records inside the shared `infinity_unified_wallet_v1` browser record. It does not claim that separate phones already share a server ledger. Named directory entries are unclaimed until verified through a future connected identity service.

The initial ten-unit balance is explicitly a local development allocation without a promised external exchange value.

## Next connection

The local record format is ready to connect with the unified Infinity wallet and Unifier service. Server synchronization must add authenticated identities, signed ledger events, idempotent request handling, creator-controlled acceptance, and an audit history before cross-device settlement is represented as live.
